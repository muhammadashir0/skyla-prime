# SKYLA PRIME — Dataset Cards

No training datasets exist yet (Phase 7). This document defines the
required card format for future datasets:

- **Name / version / date**
- **Source & license** (rights analysis required before any training use)
- **Composition** (size, languages, domains, dedup method)
- **Provenance** (collection pipeline, filters, PII screening)
- **Intended use / prohibited use**
- **Evaluation split** (held-out sets for benchmark integrity)
- **Retention & removal** (how records are deleted on request)

Retrieval corpora (PRIME KNOWLEDGE documents) are **not** training data
and must never be promoted without a rights review — see
docs/DATA_GOVERNANCE.md.
